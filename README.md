# Shankar Shinde — Cybersecurity Portfolio

A responsive, professional single-page portfolio for Shankar Shinde, focused on cybersecurity, Vulnerability Assessment and Penetration Testing (VAPT), application security, mobile security, and infrastructure assessments.

## Preview locally

1. Extract the ZIP file.
2. Open `index.html` in a browser. No build step or package installation is required.
3. The resume button opens `assets/Shankar_Shinde_Cybersecurity_Resume.pdf`.

## Before publishing

- Confirm that the GitHub URL matches your account.
- LinkedIn profile: https://www.linkedin.com/in/shankar-shinde-109357224/
- GitHub profile: https://github.com/HackWithShanku
- Review all experience dates and certification details.
- Add only client-approved, sanitized case studies. Do not publish confidential reports, client names, credentials, private evidence, or exploitable details.

## Publish with GitHub Pages

Upload the contents of this folder to a GitHub repository. In repository settings, enable GitHub Pages from the branch and folder containing `index.html` (usually `main` / root). Since this is a static site, no build command is needed.
